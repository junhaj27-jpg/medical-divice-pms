# PMS 추적 확장 설계

6: 기존 SafetyReview 연결을 유지하고 조사/조치/효과 확인 이벤트를 추가한다. 사건 잠금 → 신호 잠금 순서로 직렬화하고 요청 UUID와 요청 내용 해시를 보존한다. 종결은 연결된 모든 CAPA/리콜 완료와 효과 확인을 요구한다. 인과관계 확정 필드는 만들지 않는다. CAPA 효과 확인은 기존 CAPAEvaluation을 참조한다.

7: 제출본은 ReportArtifact 및 제출 첨부 해시, 사건 승인 해시를 고정한 별도 불변 버전이다. 제출 후 접수/보완 메타데이터는 추가 이벤트다. 제출본 자체는 수정하지 않는다. 새 제출본은 현행 승인을 요구한다. 승인 대상은 기존 approval_integrity.FIELDS 및 제출 준비 중인 보고 내용이며 제출 이후 접수번호/접수증/보완 요청/행정 처리 이벤트는 승인 대상에서 제외한다. 새 증빙도 제출 후 행정 증빙은 사건의 임상 증빙과 구분한다. 자동 제출 없음.

공통: 화면/API가 같은 서비스 함수를 호출한다. RA_QA/ADMIN만 쓰기 가능하며 ADMIN만 집계 제외 확정 가능하다. 요청 키 재사용 시 내용 불일치를 거부한다. 감사 로그에는 ID, 상태, 해시만 저장한다. 기존 스냅샷과 파일을 변경하지 않는다. 실데이터와 예시는 사건의 is_example로 분리한다.

8: 내부 PMS 정기 검토 보고서는 제품/기간/예시 구분별 불변 확정 스냅샷이다. 발생일 기준 기간 통계와 생성 시점 현재 상태를 구분한다. 내부 사건과 CSV 코호트는 출처별 별도 집계하며 합산하지 않는다. 내부 가져오기 코호트는 source_case_id로 식별하여 별도 표시한다. 과거 업무 상태 복원은 주장하지 않는다.

9: 후보 탐색은 접근 가능한 동일 제품·예시 구분에서만 수행한다. 검토 판단은 추가 이력으로 저장한다. 의심 판단만으로 제외하지 않는다. ADMIN의 명시적 확정/사유가 있을 때 앞으로 계산하는 안전 신호 통계·내부 분석 코호트 및 내부 정기 보고서 집계에서 제외하고 기존 보고서/신호 근거는 그대로 보존한다.


승인 대상 필드는 `approval_integrity.FIELDS`의 허용 목록이다. 이번 확장으로 `RegulatoryReport.submission_authority`, `submission_channel`을 추가했다. 보고 판단·조사 내용·기관·경로 변경은 재승인을 요구한다. 기존 승인 해시에 새 필드가 없으면 재승인이 필요하다. 제출 후 접수번호·접수증·보완 요청·수동 후속 기한·행정 처리 상태는 SubmissionEvent에 기록하며 승인 범위에서 제외한다. Attachment.purpose=ADMIN은 임상 근거가 아닌 제출 후 행정 증빙만을 위한 용도이며 CAPA 임상 효과 증빙으로 사용할 수 없다. 용도 변경은 금지한다.

독립 검토 단위: 0015_safety_investigation / signal_tracking.py (6), 0016_regulatory_submission / submissions.py (7), 0017_periodic_review / periodic.py (8), 0018_duplicate_review / duplicates.py (9). 공통 추적 모델·요청 키·충돌 처리와 화면/API 라우터는 공통 기반으로 분리했다.

안전 신호 종결 예외는 제공하지 않고 미완료 조치의 종결을 차단한다. 후속 제출 기한은 사유가 있는 수동 입력만 지원한다. 신규 CAPA는 기존 OPEN 상태의 조사 초안이며, 신규 리콜은 기존 DRAFT/PLANNED 상태로 생성한다. 제출본 PDF와 증빙 ZIP은 기존 ReportArtifact 체계를 재사용한다.


문서 비교 후 보완: 내부 가져오기 활성 집계에도 ADMIN 확정 제외를 적용한다. 별도 전체 보존 스냅샷 수는 제외 사건·정정 전 버전을 포함하는 보관 현황이며 사건 건수나 활성 집계와 합산하지 않는다. 기존 확정본은 재계산하지 않는다. 보존 기록의 불변 보호는 정상 애플리케이션·일반 ORM 경로에 한정되며 직접 SQL·DB 관리자·외부 파일 변조 방지나 전자서명 보증이 아니다. 상세 변경과 이번 검증 주체는 [문서 비교 후 수정](TRACKING_REVIEW_FIXES.md)을 따른다.
