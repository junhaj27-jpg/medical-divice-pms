# 시장 업무 번역 범위

`pms/market_strings.tsv`의 각 행은 키, 한국어, 영어, 독일어, 프랑스어, 스페인어, 이탈리아어입니다. 화면 언어와 원문·번역 언어, 제출 언어, 보고서 출력 언어는 각각 선택합니다. 사용자가 쓴 내용은 자동 번역하지 않습니다. 카탈로그 셀이 비어 있을 때 영어 문구를 표시하고 `pms.i18n` WARNING에 `locale`, `key`만 기록합니다. 이 경로의 회귀 검증에 `old_form_help` 키의 비어 있는 독일어·프랑스어·스페인어·이탈리아어 셀을 사용합니다.

| 화면 | 지원 또는 남은 항목 |
| --- | --- |
| 공통 내비게이션, 해외 인허가, 제품 시장 등록, 시장별 사건 상세, 버전 비교, 원문·번역, 403·404와 빈 상태, 내부 보고서 인쇄 | 6개 로캘 |
| 기존 제품·사건 상세 링크 및 기존 보고서 인쇄 | 새 화면 진입 라벨과 인쇄는 6개 로캘. 기존 상세의 과거 워크플로 양식, 검증 메시지와 일부 상태 라벨은 기존 한국어. |
| 로그인, 기존 미국·EU 신청, 일반 PMS, RA 업무 추적, 기존 규칙 작성·승인, 증빙 PDF 보존본, 관리자·API | 기존 화면의 업무 문구는 초기 번역 범위 밖이며 일부 한국어로 남음. 특히 동적 폼 오류, 업무 상태 선택지, PDF 섹션은 아직 카탈로그로 옮기지 않음. |
| 사용자 입력, 공식 원문, 증빙, 사건 설명, 규칙 제목 | 저장된 언어 그대로 표시. 검토 번역은 연결된 문서에서 선택. |
